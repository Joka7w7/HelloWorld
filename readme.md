# Overview

As a software developer, I want to continue improving my programming skills by practicing different programming languages, learning development tools, and building projects from scratch.

This project is a simple Hello World application developed using Python. It displays messages in the terminal to demonstrate how a basic Python program works.

The purpose of creating this software is to practice writing, running, and organizing Python code while becoming more familiar with Visual Studio Code, Git, and GitHub. It is also a starting point for developing more complex applications and improving my problem-solving skills.
